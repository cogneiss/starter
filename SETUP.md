# Development Setup

## Prerequisites

```bash
composer install   # also wires up the shared git hooks
bun install
```

Two optional Python tools power the code knowledge graphs. Install them if you
want graph-backed search and impact analysis (recommended — they save a lot of
time and a lot of AI tokens):

```bash
pip install graphifyy          # knowledge graph extraction
pip install code-review-graph  # call graph + impact analysis
```

Everything below degrades gracefully. If the tools are not installed, the hooks
detect it and exit quietly.

## Git hooks

`composer install` runs the `hooks:install` script, which points git at the
committed hooks in `.githooks/`:

```
git config core.hooksPath .githooks
```

Nothing else to do. To verify: `git config core.hooksPath` should print
`.githooks`.

After every commit, `.githooks/post-commit` kicks off two background rebuilds so
the graphs stay in sync with the code:

| Command | Output |
| --- | --- |
| `graphify` incremental rebuild | `graphify-out/` |
| `code-review-graph update` | `.code-review-graph/graph.db` |

Both run detached, so `git commit` returns immediately. Logs go to
`~/.cache/graphify-rebuild.log` and `~/.cache/code-review-graph-rebuild.log`.
Set `GRAPHIFY_SKIP_HOOK=1` to skip a rebuild for one commit.

The graphify portion of the hook is generated by `graphify hook install`.
Regenerate it rather than editing it by hand.

Both output directories are gitignored — they contain absolute machine paths and
are cheap to rebuild.

## Wiring the graphs into your AI editor

Each tool registers its own MCP server. Run these once per machine:

```bash
graphify claude install       # adds a CLAUDE.md section + PreToolUse hook
code-review-graph install     # registers the MCP server with your AI platform
```

`code-review-graph install` covers Claude Code, Cursor, and others; it will ask
which to configure. Neither command needs a server left running in a terminal —
MCP servers are started on demand by the editor.

## Using the graphs

The rules in `.ai/rules/general.md` tell AI agents to reach for these before
searching the codebase file by file. The same commands are useful by hand:

```bash
graphify query "how does authentication flow through this app?"
code-review-graph impact SomeClass::someMethod   # what breaks if I change this
code-review-graph architecture                   # high-level module overview
code-review-graph dead-code                      # unreferenced functions
```

If a command complains the graph is stale or missing, rebuild it directly:

```bash
graphify --update
code-review-graph update    # or: build, for a full re-parse
```

## Everyday commands

```bash
composer dev    # server + queue + logs + vite
composer test   # lint, type coverage, static analysis, unit tests
composer lint   # rector + pint + frontend lint
```
