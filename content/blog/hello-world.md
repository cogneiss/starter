This post lives in `content/blog/hello-world.md`. Every Markdown file in that
folder becomes a page at `/blog/<file name>`.

## Writing a post

Start the file with front matter: `title`, `description` and `date` are
required, `author` is optional, and `draft: true` hides the post in production.

## Changing the content

Delete this file and add your own. There is no admin screen; a post is a commit.
